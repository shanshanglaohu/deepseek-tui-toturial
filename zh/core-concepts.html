核心概念

理解让 DeepSeek TUI 成为高效 AI 协作伙伴的基础理念。

Agent 模式

DeepSeek TUI 在不同的模式下运行，控制其自主程度。为任务选择合适的模式是你最重要的决策之一。

Plan 模式（计划模式）

Plan 模式为只读调查。Agent 可以 grep、读取文件、列出目录、获取 URL——但不能写入文件或执行 Shell 命令。适合安全探索。

  • 适用场景：代码库探索、查阅文档、不熟悉的项目
  • 行为特征：纯只读，零副作用，不会修改任何文件
  • 安全性：最高——无写入或执行能力

Agent 模式（默认）

默认的多步骤工具使用模式。Shell 和有副作用的工具根据 approval_mode 设置需要审批。

  • 适用场景：日常开发、代码修改、测试运行
  • 行为特征：创建计划和清单，关键操作请求审批
  • 安全性：中等——依据审批策略控制

YOLO 模式（全自动模式）

YOLO 模式赋予 Agent 完全自主权——自动批准所有操作并启用信任模式，工作空间边界解除。请谨慎使用。

  • 适用场景：明确定义的任务、可信工作流、快速迭代
  • 行为特征：快速行动、立即执行，仍会创建清单以便追踪
  • 安全性：较低——信任 Agent 或事后审查变更
🔄 模式切换

按 Tab 循环切换模式（Plan → Agent → YOLO），Shift+Tab 切换推理深度。探索不熟悉的代码时从 Plan 模式开始，日常开发使用 Agent 模式，任务明确时使用 YOLO 模式。

Auto 模式（智能路由）

使用 --model auto 时，DeepSeek TUI 会自动为每一轮选择最合适的模型和推理深度，无需手动切换。

Auto 模式如何工作

  1. 在发送真实请求前，先用 deepseek-v4-flash（无推理）做一个轻量路由调用
  2. 路由器根据你的请求内容和上下文，选择具体的模型和推理级别
  3. 简单问题 → Flash + 无推理；编码/调试/架构 → Pro + 高推理
Shell
# 启动时开启 Auto 模式
$ deepseek --model auto

# 或在会话中使用命令切换
/model auto
🎯 推荐新手使用 Auto 模式

不确定选哪个模型？直接用 --model auto。系统会自动决策，兼顾成本和效果。TUI 头部会显示实际使用的模型。

思考预算

DeepSeek V4 模型会生成思考 token——用于提升输出质量的内部推理，但会消耗上下文空间。DeepSeek TUI 允许你控制这个权衡。

预算等级

任务类型深度示例
简单查询跳过读取文件、搜索模式
工具输出解读轻度验证 grep 结果
代码生成中等编写单个函数
多文件重构中等跨文件依赖变更
调试排错深度根因分析
架构设计深度权衡分析、约束建模
安全审查深度对抗性推理

思考一次，多次引用。将结论缓存为简洁的内联摘要，而不是每轮重新推导。这样可以在长会话中保持思考效率。

分解哲学

DeepSeek TUI 是一个"受控天才"——它在单项任务上表现出色，但真正的超能力是分解复杂工作。三种模式支配着这个过程：

PREVIEW — 行动前先勘测

在处理大型任务之前，先扫描目录结构、文件头部和模块树。30 秒的预览可以避免数小时的错误方向探索。

CHUNK + Map-Reduce（分块+归并）

拆分为独立子任务，并行处理每个子任务（通过子代理或并行工具调用），然后将发现综合成连贯的整体。

RECURSIVE 递归分解

当子任务揭示子问题时：递归分解直到每个叶子任务可处理。维护任务树并将发现向上传播。

上下文窗口与缓存

DeepSeek TUI 拥有1M token 的上下文窗口和智能前缀缓存系统。理解其工作原理有助于从长会话中获得最大价值。

前缀缓存经济学

  • V4 以 128 token 粒度缓存共享前缀
  • 缓存命中获得约 90% 的成本折扣
  • 追加到现有消息可保留缓存
  • 删除或修改旧消息会破坏缓存

缓存管理

  • 追加，不要重排——新内容放在末尾
  • 不要改写引用内容——按路径或行范围引用
  • 将 /compact 用作硬重置，而非微调
  • 读取一次，反复引用——重新读取会破坏缓存

会话管理

DeepSeek TUI 支持保存、恢复和分叉会话。即使终端关闭、电脑重启，也能从上次中断处继续。

关键操作

  • 自动保存：每次对话自动保存，无需手动操作
  • 恢复会话：deepseek resume --last 恢复最近一次会话
  • 分叉会话：deepseek fork <SESSION_ID> 在某个轮次创建分支
  • 列出会话：deepseek sessions 查看所有已保存的会话
  • 回滚：/restore 或 revert_turn 回退到之前的状态（不影响你的 git 仓库）
💾 工作空间隔离

会话按工作空间范围保存和列出。项目 A 的会话历史不会泄露到项目 B 中。每个项目维护独立的会话列表。

工具系统

DeepSeek TUI 提供了一套结构化的工具箱来与你的项目交互。所有工具在安全工作空间边界内运行。

工具分类

📁
文件 I/O
read_file, write_file, edit_file, apply_patch — 安全、受工作空间约束的文件操作。
💻
Shell
exec_shell, task_shell_start — 运行命令、测试、构建和长时间进程。
🔍
搜索
grep_files, file_search, web_search — 查找代码模式、文件和网络资源。
📋
规划
update_plan, checklist_write — 结构化任务跟踪，进度可见。

并行优先策略

在调用任何工具之前，先检查你的清单：是否有另一个可以并发运行的工具？调度器会同时执行并行工具调用——串行化独立操作浪费时间和上下文空间。

键盘快捷键

掌握以下快捷键可以大幅提升操作效率：

按键功能
