快速入门

几分钟内完成安装、配置并启动你的第一个 DeepSeek TUI 会话。

什么是 DeepSeek TUI？

DeepSeek TUI 是一个基于终端的 AI 编程助手，由 DeepSeek V4 模型驱动。 它直接运行在你的终端中，为你提供一个能够：

  • 读写文件：在项目工作空间中操作文件
  • 执行 Shell 命令：运行测试、构建和诊断命令
  • 搜索和导航：使用结构化工具浏览代码库
  • 分解复杂任务：拆分为计划、清单和子代理工作流
  • 自主运行：在 YOLO 模式下全自动，或在 Plan 模式下协作
🖥️ TUI = 终端用户界面

不同于基于网页的 AI 工具，DeepSeek TUI 完全运行在终端中。这意味着它拥有直接的文件系统访问权限、Shell 集成能力，并自然地融入你现有的 Unix 工作流。

安装

Linux 和 macOS

通过 Cargo 安装

Shell 
$ cargo install deepseek-tui-cli --locked
$ deepseek

通过 npm 安装

Shell 
$ npm i -g deepseek-tui
# 首次运行将自动设置 ~/.deepseek/

需要 Rust 1.88+ 或 Node >=18。

通过 Homebrew 安装（macOS）

Shell 
$ brew tap Hmbown/deepseek-tui
$ brew install deepseek-tui

直接下载（无需包管理器）

从 GitHub Releases 下载预编译二进制文件。支持 Linux x64/ARM64、macOS x64/ARM64、Windows x64。

通过 Docker 运行

Shell 
$ docker run --rm -it \
    -e DEEPSEEK_API_KEY \
    -v "$PWD:/workspace" \
    ghcr.io/hmbown/deepseek-tui:latest

Windows

WSL2（推荐）

在 WSL2 终端内按照 Linux 安装步骤操作即可，原生运行。

Scoop 包管理器

PowerShell 
$ scoop update
$ scoop install deepseek-tui
$ deepseek --version
🇨🇳 国内用户

npm 安装慢时使用 --registry=https://registry.npmmirror.com。Cargo 用户可配置清华镜像加速。

验证安装

Shell 
$ deepseek --version
deepseek-tui 0.8.31

API Key 设置

首次启动时会提示输入 DeepSeek API Key（在此获取）。也可以提前设置：

Shell
# 保存到配置文件（推荐，跨目录生效）
$ deepseek auth set --provider deepseek

# 查看当前认证状态
$ deepseek auth status

# 或使用环境变量（适合非交互式 Shell）
$ export DEEPSEEK_API_KEY="sk-your-key-here"

# 检查配置是否正常
$ deepseek doctor
💡 认证优先级

保存到配置文件的 Key 优先级最高，也最易于轮换。使用 deepseek auth clear --provider deepseek 可移除已保存的 Key。如果 deepseek doctor 报告 Key 被拒绝，检查是否有过期环境变量覆盖。

配置

DeepSeek TUI 的配置存储在以下两个关键位置：

配置文件 
~/.deepseek/           # 主配置目录
├── config.toml        # 核心配置
├── instructions.md    # 自定义项目说明（自动生成）
├── skills/            # 已安装技能
├── memories/          # 持久化记忆存储
└── plugins/           # 插件系统

基本设置

编辑 ~/.deepseek/config.toml：

config.toml
[api]
key = "sk-..."
base_url = "https://api.deepseek.com"
model = "deepseek-v4-pro"  # 默认；deepseek-v4-flash 为快速/子代理选项

[ui]
default_mode = "agent"     # plan | agent | yolo
approval_mode = "suggest"  # suggest | auto | never
reasoning_effort = "high"  # off | high | max

项目说明文件

项目根目录下的 instructions.md 文件自动生成，用于告知 DeepSeek TUI 你的项目结构、语言偏好和工作空间边界。你可以编辑它以添加项目特定的指导。

首次使用

  1. 进入你的项目目录
    Shell
    $ cd ~/my-project
  2. 启动 DeepSeek TUI
    Shell
    $ deepseek
  3. 编写你的第一条提示词

    界面会在终端中打开。尝试一个简单任务来熟悉操作：

    DeepSeek TUI
    总结项目结构和关键文件。
✅ 首次会话成功

Agent 会读取你的项目文件，返回分析结果，然后等待你的下一条指令。你现在已经开始了与 AI 的结对编程。

更多启动方式

Shell
# 交互式 TUI（默认）
$ deepseek

# 单次提问（非交互模式）
$ deepseek "解释这个函数的作用"

# 指定模型
$ deepseek --model deepseek-v4-flash "总结一下 README"

# 自动选择模型和推理深度（推荐新手使用）
$ deepseek --model auto "修复这个 bug"

# 全自动模式（自动批准所有操作，谨慎使用）
$ deepseek --yolo

# 查看可用模型
$ deepseek models

# 列出已保存的会话
$ deepseek sessions

# 恢复上次会话
$ deepseek resume --last

工作空间模型

DeepSeek TUI 在工作空间中运行——即你启动它的目录。 所有文件操作都相对于此根目录。这是一个安全边界： 在没有显式信任模式的情况下，工具无法读取或写入工作空间之外的文件。

关键概念

  • 工作目录：传递给 deepseek 或通过 cd 设置的目录
  • 工作空间根目录：顶层项目目录
  • 活跃路径：Agent 当前关注的文件
  • 信任模式：需要时授予工作空间之外的访问权限
⚠️ 安全提示

默认情况下，DeepSeek TUI 将文件访问限制在工作空间内。仅在需要跨项目操作时启用信任模式，并仔细审查工具调用。

沙箱保护

DeepSeek TUI 利用操作系统级沙箱机制限制工具执行范围：

  • Linux：landlock
  • macOS：seatbelt
  • Windows：AppContainer / restricted tokens

常见问题排查

API Key 被拒绝

症状：deepseek doctor 报告 Key 无效或被拒绝。

  • 运行 deepseek auth status 查看当前认证来源
  • 检查是否有过期环境变量 DEEPSEEK_API_KEY 覆盖了配置
  • 运行 deepseek auth set --provider deepseek 重新设置
  • 确认 Key 来自 DeepSeek 平台，未过期

命令找不到（command not found）

症状：终端提示 deepseek: command not found。

  • Cargo 安装：确认 ~/.cargo/bin 在 $PATH 中
  • npm 安装：确认 npm 全局 bin 目录在 $PATH 中（npm bin -g 查看）
  • 重新打开终端或运行 source ~/.bashrc

Agent 输出不符合预期

症状：Agent 生成的代码与你的需求不符。

  • 提示词不够具体：参考 提示词工程 改进描述
  • 上下文过长：运行 /compact 压缩后重试
  • 模式不对：Plan 模式不能写文件，确认在 Agent 或 YOLO 模式

操作失误如何撤销

  • 撤销最近一轮：在对话中输入 /restore 回退文件
  • 撤销指定轮次：使用 revert_turn 工具
  • Git 保护：操作不会影响你的 .git 目录，可随时 git diff 查看变化
🩺 诊断命令

遇到问题时先运行 deepseek doctor — 它会检查配置、连接性和常见配置错误，并给出修复建议。
