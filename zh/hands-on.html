实战教程：构建个人作品集网站

全程使用 DeepSeek TUI，从零开始创建一个完整的单页个人作品集网站，并部署到线上。

🎯 学完本章你将掌握
  • 如何用自然语言描述项目需求让 DeepSeek 生成完整代码
  • 如何在 Agent 模式和 Plan 模式之间切换完成不同任务
  • 如何审查、反馈、迭代 AI 生成的代码
  • 如何从零到部署完成一个完整项目

第一步：准备工作

1.1 创建项目目录

终端
$ mkdir ~/my-portfolio
$ cd ~/my-portfolio

1.2 启动 DeepSeek TUI

使用 Agent 模式启动（默认模式，适合有写入操作的任务）：

终端
$ deepseek

1.3 描述你的项目

这是最重要的步骤。提示词越具体，结果越精准。复制下面的提示词：

DeepSeek TUI — 第一条提示词
我要创建一个单页个人作品集网站。请按以下要求创建：

项目结构：
- index.html（主页面）
- css/style.css（样式）
- js/main.js（脚本）

页面内容：
1. 导航栏：固定在顶部，包含"首页、关于我、技能、项目、联系"五个链接
2. 英雄区：名字（用"张三"做占位）、一句话简介、一个 CTA 按钮
3. 关于我：两段介绍文字（写占位内容）
4. 技能区：6 个技能卡片（HTML、CSS、JavaScript、Python、Git、Linux），每个带图标
5. 项目区：3 个项目卡片，每个包含标题、描述和技术标签
6. 联系方式：邮箱和社交媒体链接

设计要求：
- 深色主题（背景 #0e0e10，文字浅色）
- 响应式布局（桌面和手机都好看）
- 使用 CSS 变量管理颜色
- 滚动到对应区域时导航高亮

请先列出文件结构计划，经我确认后再生成代码。
💬 提示词拆解

注意这个提示词的结构：明确输出的文件列表 + 逐区域描述 + 设计约束 + 先计划后执行。最后一句"先列计划"让 Agent 在写代码前展示结构，给你审查机会——避免生成后发现方向不对。

1.4 确认计划

Agent 会返回文件结构计划并征求你的确认。审查后回复"确认"或"可以"让其开始生成代码。

第二步：生成骨架

Agent 会依次创建 index.html、css/style.css、js/main.js。

2.1 预览成果

生成完成后，在浏览器中打开看看效果：

终端（WSL）
$ cmd.exe /c start index.html

在 macOS 上使用 open index.html；Linux 用 xdg-open index.html。

2.2 如果效果不对……

直接告诉 Agent 哪里需要改。例如：

DeepSeek TUI
导航栏的背景色太深了，改成半透明效果。另外英雄区的文字大小在手机上太大，请缩小。

第三步：审查与迭代

3.1 切换到 Plan 模式做代码审查

按 Tab 切换到 Plan 模式（只读），让 Agent 审查代码而不做修改：

DeepSeek TUI（Plan 模式）
审查 css/style.css 的响应式设计。检查是否有：
1. 遗漏的断点
2. 不一致的间距
3. 可访问性问题（对比度不足等）

只报告问题，不要修改。
🔄 模式切换策略

审查用 Plan 模式（安全，不误改）→ 修改用 Agent 模式（有审批门禁）→ 批量简单任务用 YOLO 模式（快速）。按 Tab 循环切换。

3.2 替换占位内容

让 Agent 帮你批量替换占位文字：

DeepSeek TUI
把页面中所有"张三"替换为我的真实姓名。把技能描述、项目描述、关于我文字都换成更自然的占位内容——不要用"Lorem ipsum"。

第四步：添加高级功能

4.1 添加暗色/亮色模式切换

DeepSeek TUI
给网站添加暗色/亮色主题切换功能：
- 导航栏右侧放一个切换按钮（☀️/🌙）
- 点击切换 data-theme 属性（dark ↔ light）
- 定义两套 CSS 变量
- 用 localStorage 记住用户选择
- 修改 js/main.js 和 css/style.css

4.2 添加平滑滚动和动画

DeepSeek TUI
增强用户体验：
- 点击导航链接时平滑滚动到对应区域
- 滚动到可视区域时，技能卡片和项目卡片用淡入效果出现
- 使用 IntersectionObserver 实现（不要引入第三方库）
⚡ YOLO 模式提速

当你在修改一个自己完全理解的文件、且改动方向明确时，按 Tab 切到 YOLO 模式可以跳过审批步骤，大大提速。完成后再切回 Agent 模式。

第五步：审查与部署

5.1 最终审查

切回 Plan 模式做最终检查：

DeepSeek TUI（Plan 模式）
对整个项目做最终审查。检查：
- 所有链接是否有效
- 移动端在 375px 宽度下的表现
- 图片 alt 文本是否齐全
- 页面加载性能（是否有阻塞渲染的资源）
列出发现的所有问题。

5.2 初始化 Git 并提交

终端
$ git init
$ git add .
$ git commit -m "初始化个人作品集网站"

5.3 部署到 GitHub Pages（免费）

  1. 在 GitHub 创建新仓库 my-portfolio
  2. 推送代码：
终端
$ git remote add origin git@github.com:你的用户名/my-portfolio.git
$ git branch -M main
$ git push -u origin main
  1. 在 GitHub 仓库 → Settings → Pages → Source 选择 main 分支
  2. 几分钟后访问 https://你的用户名.github.io/my-portfolio
✅ 恭喜！

你已经用 DeepSeek TUI 从零构建并部署了一个完整的个人作品集网站。整个过程中，你编写的是需求描述而非代码——这是 AI 辅助开发的核心工作流。

使用技巧总结

高效提示词的五个要素

要素示例
1. 输出物"创建三个文件：index.html、style.css、main.js"
2. 逐区域描述"导航栏包含……英雄区包含……技能区包含……"
3. 设计约束"深色主题、响应式、纯 CSS 变量"
4. 技术限制"不引入第三方库、使用 IntersectionObserver"
5. 先计划后执行"先列出文件结构，确认后再生成代码"

典型的迭代循环

  1. 描述需求 → Agent 生成代码
  2. 预览结果 → 浏览器查看效果
  3. 反馈问题 → "导航栏太暗了，改成半透明"
  4. 审查代码 → 切 Plan 模式检查
  5. 重复 1-4 直到满意

模式选择速查

你在做什么用哪个模式
探索项目、审查代码Plan（只读，安全）
写代码、改文件、日常开发Agent（默认，有审批）
批量替换、信任的重复操作YOLO（快速，无审批）
